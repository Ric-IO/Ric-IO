### 🚀 Projeto em Destaque

**Sistema IoT para Detecção Inteligente de Vazamentos de Gás** *(TCC)*

Desenvolvi um sistema completo com ESP32 e sensor MQ-2 para monitoramento de GLP, CO e fumaça. O projeto integra notificações em tempo real via WhatsApp (API CallMeBot) e acionamento automático de servo motor, alarme sonoro e display TFT. Testes de bancada validaram tempo de resposta inferior a 2 segundos.

**Tecnologias utilizadas:** ESP32, C++, Arduino IDE, MQ-2, Servo Motor, Display TFT, WhatsApp API (CallMeBot).
